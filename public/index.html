API Documentation

GET /api/students

Returns a list of all 100 students. Requires x-api-key header.

GET /api/students/search

Search students by Name or Age range (e.g. 15 to 17). Requires x-api-key header.

GET /api/students/{id}

Returns information for a specific student by their ID (1 to 100). Requires x-api-key header.
